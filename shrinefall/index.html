Reaching a human

One person builds and answers for Shrinefall. Post to rld.ranger07@gmail.com and the answer arrives from that same mailbox — there is no ticket portal and no bot in between.

Three things make a bug easy to chase, so include them if you can:

Handset
iPhone or iPad model, and the iOS version.
Moment
Which screen you were on, and what you had just tapped.
Mode
Alone, hosting a room, or joined to someone else's.

Getting a party together

Both handsets need the internet and the same version of the game. Playing by yourself needs neither.

  1. The host taps CO-OP, then HOST A ROOM. A six-character room code appears in gold under the words ROOM CODE.
  2. Everyone else taps CO-OP, types that code into the box, and taps JOIN.
  3. Each guest picks a hero on the party screen and taps READY.
  4. The host taps START, and the world opens for every filled seat. Four is the ceiling.

Nothing you find is taken from you: loot rolls separately for each player, and kills you are near — within forty tiles — share their experience with the rest of the party.

Questions that come up

The code will not connect

Room codes live only as long as the host stays in the room. If the host backed out, the code is already dead and a fresh one is needed. Check as well that both handsets are on the same version of the game: a host turns away any build whose network protocol differs from its own.

Where do my heroes live?

In a single save file inside the app on your own device. It never travels to us, and it does not follow you to a second device. Removing the app removes the save with it, and there is no backup we can restore from.

Can I change the name I typed?

Yes, at any time, on the hero-choosing screen where you first typed it. It holds sixteen characters and reads Wanderer until you put something else there. Only a party you handed a room code to ever sees it.

Is anything for sale?

No. Shrinefall carries no shop, no currency you can buy, no advertising and no subscription. The download itself is free, so no money changes hands at any point.

Where the art and music come from

Shrinefall's visuals and audio are licensed packs by other artists; none of it was produced in-house:

  • Ninja Adventure Asset Pack — Pixel-boy & AAA (CC0): actors, bosses, tilesets, items, FX, UI, music, sounds
  • Pixel Crawler Free Pack — Anokolisa: environment props
  • 0x72 Dungeon Tileset II (CC0): dungeon props
  • Kyrise's Free 16x16 RPG Icon Pack, RPG Arsenal (LimeZu), Pixel Art Icon Pack – RPG: item icons
  • Kenney Mobile Controls & Kenney RPG Audio (CC0): joystick, buttons, interface sounds
  • 28 High Quality 16-bit RPG Music — HydroGene: boss themes
  • Barlow — Jeremy Tribby (SIL OFL 1.1): body typeface

The same list sits behind the CREDITS button on the title screen — its own button there, not a page buried in SETTINGS.
